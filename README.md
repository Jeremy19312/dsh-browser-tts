# dsh-browser-tts
DSH 前端TTS插件，基于浏览器原生 speechSynthesis，本地语音播报，不消耗Token！

## ✨ 特性
- 纯前端运行，不需要后端TTS服务
- 使用浏览器自带语音引擎，机械感原生音色
- 不向第三方上传文本，零token开销
- 支持开关控制播报

## 📦 安装
dsh-browser-tts
## 📝 说明
- 音色由你的系统/浏览器自带语音包决定，不同设备声音不一样
- 长文本可能截断（Web Speech API原生限制）
- 仅在WebUI页面生效
